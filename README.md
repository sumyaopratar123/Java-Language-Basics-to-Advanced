# Java Basics — 500 Code Files

A beginner-only collection of 500 standalone `.java` programs. It intentionally focuses on fundamentals and does not aim to cover advanced Java topics.

## Topics
- Hello World and output
- Variables, data types, constants and type casting
- Arithmetic, relational and logical operators
- Scanner input
- if/else and switch
- for/while/do-while loops
- Basic number programs and patterns
- Arrays and strings
- Methods and simple recursion
- Introductory classes and objects
- Basic exceptions and collections
- Everyday calculation examples and practice exercises

## Run a program (Windows PowerShell)
Install a JDK and make sure `java` and `javac` are available in PATH.

```powershell
cd .\01_Hello_Output
javac HelloWorld.java
java HelloWorld
```

Every `.java` file is intended to be run separately. Many practice examples use simple hard-coded values; edit them to practise.
